# dx-demo-launcher

## 🚀 Quick Start

### Prerequisites

- Python 3.8+
- DEEPX NPU SDK

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/DEEPX-AI/dx-clip-starter
   cd dx-clip-starter
   ```

2. **Install python3-pyqt5**
   ```bash
   sudo apt update
   sudo apt install python3-pyqt5
   ```

3. **Create virtual environment**
   ```bash
   python3 -m venv --system-site-packages .venv-launcher
   source .venv-launcher/bin/activate
   ```
